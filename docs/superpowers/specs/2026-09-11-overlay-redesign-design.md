# Overlay and Control Panel Redesign — Design Spec

Date: 2026-09-11
Scope: `index.html` (skip overlay + control panel), `queue_widget.html` (music panel). No backend changes.

## Goals

1. Overlays read as one calm, modern system over live video ("album-art glass").
2. Viewers see only what helps them: what's playing, what's next, how to request, how to skip.
3. The control panel becomes a dashboard the streamer can scan at a glance.
4. Every existing script hook and browser-test contract keeps working.

## Non-goals

- No new features, no new socket events, no server-side changes.
- No change to URL parameters or their meaning (`bg`, `transparent`, `controls`, `queue_source`, `demo`).
- No change to the security posture (CSP stays as generated by `_overlay_response`).

## Design system

### Surfaces

- Glass card: `background: rgba(12,14,18,0.72)`, `backdrop-filter: blur(18px) saturate(140%)`, `border: 1px solid rgba(255,255,255,0.10)`, `border-radius: 20px`, `box-shadow: 0 12px 40px rgba(0,0,0,0.45)`.
- Art backdrop (Now Playing hero only): absolutely positioned layer using the current album art, `background-size: cover`, `filter: blur(40px) brightness(0.55) saturate(1.3)`, `transform: scale(1.3)`, `opacity` 0.6, clipped by the card. Falls back to a neutral dark gradient when no art.
- Accent: CSS variable `--accent`, default `#8b7cff`. Sampled client-side from album art (small canvas average, saturation boosted, luminance clamped to 0.45–0.75). Sampling failure (CORS, decode) leaves the default. Accent drives the progress bar, skip ring, live dot, and count badge.
- Opaque mode (`?bg=black`, `/control`): same cards without blur dependency; base alpha raised to 0.92.

### Typography

- Display and numbers: Plus Jakarta Sans 600/700/800.
- Body and labels: Inter 500/600.
- Loaded from Google Fonts (already allowed by CSP). No uppercase tracking, no italics, no serif.
- Numerals use `font-variant-numeric: tabular-nums`.
- Scale (portrait source ≈ 420px wide): hero title 26–30px, row title 17px, row meta 13px, ETA 15px, hints 13px. Landscape wide sources scale up ~15% via `clamp()`.
- Over-video text gets `text-shadow: 0 1px 2px rgba(0,0,0,0.6)`.

### Motion

Kept: progress bar (linear), row slide-in on add (250ms), skip ring fill (600ms ease-out), one-shot pulse ring on new vote, breathing "playing" dot (2.4s). Removed: background particles, rotating conic borders, glowing titles, pulsing CTA pill, arrow bounce, icon shake, shimmer, equalizer bars, floating notes/`!SKIP` text, vote particle burst. `prefers-reduced-motion: reduce` disables all animation and transitions.

Functions `spawnNotes`, `spawnSkipFloat`, `spawnSkipBurst` remain defined but become no-ops (safe for callers and tests).

### Adaptive layout

- `@media (orientation: portrait)` or width < 640px: single column, larger type.
- `@media (min-aspect-ratio: 4/3) and (min-width: 640px)`: queue widget uses two columns (Now Playing left ≈ 40%, Up Next right).

## Pages

### `queue_widget.html` — music panel

Structure (ids/classes in **bold** are contracts):

- `.widget` root; **`#connection-status`** banner (hidden when connected).
- Now Playing hero `.panel.now`: `.now-backdrop` art layer; **`#now-art`** (rounded 12px, 96–160px); eyebrow "Now playing" with `.live-dot`; **`#now-track`** title (2-line clamp) and artist on separate lines — `renderNow()` keeps setting `label = title - artist` into `#now-track`; add `#now-artist` and split rendering (title into `#now-track`, artist into `#now-artist`) while keeping `#now-track` text non-empty. **`#now-time`** and **`#now-state`** remain; `#now-state` becomes a small dot+word indicator.
- Progress **`#now-bar`** inside `.bar` (4px high, accent fill).
- Up Next `.panel.queue-panel`: header "Up Next" with **`#queue-count`** chip; **`#queue-status`** rendered as a compact chip that is visually shown only when `data-level="warn"` (connection lost, sync unavailable, not configured). Informational source text is still written to `textContent` but hidden with `[data-level="info"] { display:none }`.
- **`#queue-list`** rows `.queue-item`: position number, `.art` thumbnail (only when art exists), `.song` title, `.meta` line "Artist · requested by user", right column `.eta` with `.eta-start[data-index]` ("in 2:05") and `.eta-end[data-index]` ("ends 5:25", muted). Empty state `.empty`: "Nothing queued yet — type !req Song by Artist".
- Footer `.request-hint` pill: "Request: **!req Song by Artist** · Skip: **!skip**".
- **`#request-toast`**, **`#request-toast-text`**, **`#request-toast-icon`** kept; restyled as a glass pill.
- Globals kept: `requestQueueItems`, `spotifyQueueItems`, `spotifyQueueStatus`, `syncQueueSourceAndRender`, `handleNow`, `currentElapsedSec`, `nowAnchorMs`, `renderQueue`.

### `index.html` — skip overlay (`/`) and control panel (`/control`)

Overlay defaults unchanged: transparent background, requests panel hidden (`.requests-panel.hidden-panel`), compact skip meter (`.compact-skip`).

Skip meter (**`#voting-panel`**): in transparent mode the panel itself has no background, border, shadow, or backdrop-filter, and `.border-glow`/`.glow-line` are `display:none` (contract). Inside: **`#skip-meter-circle`** ring (SVG **`.skip-circle-bg`**, **`#skip-circle-fill`**, **`#skip-ring`**), center **`#skip-count`** (large, text-shadow), **`#skip-of-text`**, **`#skip-mode-text`** (hidden in compact); below the ring **`.skip-command-hint`** with **`.skip-command-box`** "!skip" and `.skip-cta-text` "to vote". **`#skip-bar-fill`**, **`#recent-skippers`**, **`#skip-warning`**, **`#skip-count-badge`**, **`#now-playing-track`**, **`#now-playing-time`**, **`#now-playing-line`** remain in the DOM (some hidden in compact mode). States: `.danger` at ≥50% (ring color shifts warm), `.full` at 100% (pulse, `#skip-warning` shows "Skipping…"). Content must fit inside the panel and inside 200×200 / 320×240 sources; the bottom-center pixel (100,190) of a 200×200 source stays transparent.

Requests panel (`.requests-panel`, shown when the streamer enables it): header "Song Requests" + **`#request-count`** chip; **`#request-list`** rows `.request-item` styled like Up Next rows: number, optional `.art` (only when `item.album_art` exists — the browser test asserts zero `img` for art-less items), `.song-name > .song-name-inner` (marquee only on overflow), `.artist-name`, **`.user-tag`**, `.eta-tag[data-index]`. `.newest` gets an accent left rule. Empty state simplified. CTA pill, LIVE badge, footer, item watermark removed.

Control panel (`body.controls-mode`): 
- **`.control-heading`** becomes the dashboard header: title, off-stream warning, overlay links, and a status strip `#control-status` with four tiles: connection (`#status-connection`), now playing (`#status-now`), requests (`#status-requests`), skip votes (`#status-skips`). Tiles are updated from existing handlers (`renderQueue`, `updateSkipMeter`, now-playing render, connect/disconnect) with null-safe lookups.
- Cards grid `.control-grid`: **`#control-auth`** (Unlock), **`.mod-bar`** (Moderator controls, toggle **`#mod-toggle`** → **`#mod-panel`**), **`.test-bar`** (Test chat, toggle **`#test-toggle`** → **`#test-panel`**). Three columns ≥ 1000px, one column below. All existing ids inside the cards unchanged.
- Preview card `.preview-card` wraps `.widget-wrapper` with label "Overlay preview — what viewers see". Voting panel is opaque here (contract).
- Form controls: 44px min height, consistent radius, focus ring `outline: 3px solid var(--accent)`.

## Behavior notes

- Accent sampling runs when `album_art` changes; cached per URL. Uses `Image` with `crossorigin="anonymous"`; any exception is swallowed.
- Long titles: CSS `-webkit-line-clamp: 2` in the hero; single-line ellipsis in rows (marquee kept in `index.html` rows only where it already exists).
- Toast timing unchanged.
